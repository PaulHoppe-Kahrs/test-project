# Einfaches PHP Projekt

Dies ist ein kleines PHP-Projekt mit einer To-Do-Liste.

## So startest du das Projekt

1. Öffne ein Terminal im Projektordner.
2. Führe folgenden Befehl aus:

```bash
php -S localhost:8000
```

3. Öffne danach deinen Browser unter:

```text
http://localhost:8000
```

## Funktionen

- Neue Aufgaben hinzufügen
- Aufgaben in der Session speichern
- Liste leeren
- Einfaches Design

## Dateiübersicht

- `index.php` – Hauptseite und Logik
- `style.css` – Styling
