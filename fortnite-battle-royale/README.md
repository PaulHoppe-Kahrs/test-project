# Battle Royale Mini

Ein einfacher Fortnite-ähnlicher Battle-Royale-Prototyp mit:

- WASD-Bewegung
- Maus-Aiming
- Schießen mit Linksklick
- Zone, die sich langsam zusammenzieht
- Bots, Loot und Trefferlogik
- Win/Lose-Zustände

## Starten

Im Projektordner:

```bash
python3 -m http.server 8010
```

Danach im Browser:

```text
http://localhost:8010
```

## Steuerung

- WASD: Bewegen
- Maus: Zielen
- Linksklick: Schießen
- Überlebe bis alle Gegner besiegt sind
